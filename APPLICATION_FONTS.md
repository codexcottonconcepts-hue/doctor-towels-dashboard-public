# Application font

The application uses the existing embedded Satoshi family across dashboards, chart labels, forms, registers, reports, sign-in and account controls. Typography roles follow the Online Sales reference: medium 28px KPI values (24px in compact views), 12px labels and panel headings, and regular 12px notes. The shared dashboard header keeps its compact sizing, comparison names retain automatic fitting, and gauge/donut centre sizes remain unchanged. Compact SVG charts use chart-specific label sizes so category names and order counts stay readable; the two large TV charts keep 12px labels. Only font family, size, weight, line height and letter spacing are overridden; colours, layout rules, data and access remain in place.

The shared dropdown assets carry the family override. Server pages embed the font faces there unless their head already contains them. Dashboard rendering reuses its existing head font faces and requests the override without a duplicate font set. The source font asset is unchanged and makes no external request.
